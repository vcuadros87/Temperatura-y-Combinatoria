# Temperatura-y-Combinatoria
Estos proyectos son dos simuladores matemáticos desarrollados con HTML5, CSS3 y JavaScript.

### 1. Transferencia de Calor (Ley de Enfriamiento de Newton)
Esta sirve para calcula la temperatura final de un objeto tras un tiempo determinado dentro de un entorno a temperatura constante.

**Fórmula:** `T = Ts + (T0 - Ts) * e^(-k * t)`

T0  .-Temperatura inicial del objeto 
Ts  .-Temperatura del entorno 
k .- Constante de enfriamiento 
t  .- Tiempo transcurrido (horas) 

### 2. Calculador de Combinaciones 
Esta sirve para calcula el total de combinaciones posibles para un sorteo con dos grupos independientes.

**Fórmula:** `C(n, r) = n! / (r! * (n - r)!)`

El resultado total es el producto de ambos grupos: `C(n1, r1) × C(n2, r2)`
